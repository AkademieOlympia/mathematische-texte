	\begin{abstract}
		Wir dokumentieren Historie und Würdigung eines formal-rechnerischen Programms zur adaptiven Zylinder-Abdeckung für Collatz-Abstiege im Bamberg-/Kepler--Hurwitz-/eabc-renorm-Kontext. Das Programm vereint Margin-/Strip-Kontraktion, Syracuse-Entropiekompression, Lean-Module \texttt{CylinderLift31/447}, den Draft-PR \#118 sowie eine eingefrorene Offline-Phase \texttt{pre-\#119} (Master-Evaluator-Gap-Matrix, Prefix \texttt{[1,1,1,1,2,2]}, \texttt{ContinuationPartition31}). Auf dem endlichen $2^{22}$-$\U_6$-Sample berichten wir echte diagnostische Kennzahlen (\textit{packaged 8} $\approx 21{,}9\%$; \textit{Core81} $\to \approx 50\%$; $2519$ Muster $\to 100\%$ Sample [B]; \textit{CoveredUpTo} $\approx 33$--$65\%$; $\equiv 447$-Leiter $520 \to 35\%$, $\mathrm{len}16 \to 58{,}9\%$, \textit{greedy 1336} $\to 50\%$, \textit{steps150 4066} $\to 100\%$ Sample, Hard-17 rescued). Lokale Lean-Builds \texttt{Core81} und \texttt{Phase1\_447Base} sind grün; Claims bleiben \texttt{False}. \textbf{Collatz bleibt unbewiesen:} finite Sample-Coverage ist keine unendliche Restklassen-Partition.
	\end{abstract}
	
	\noindent\textbf{Keywords:} Collatz (offen), adaptive cover, cylinder lift, Syracuse, entropy compression, Lean 4, claim governance, eabc-renorm, HardAncestor $\equiv 31/447 \pmod{512}$.

	\section{Historie (ohne Erfolgsmythos)}
	
	\begin{enumerate}
		\item \textbf{Margin/Strip:} Lokale Kontraktion, \texttt{boundN}, bedingte Glue-Schnittstelle $\mathrm{CoverCertified} \implies \mathrm{DescentU6} \implies \mathrm{ReachesOne}$ [A bedingt]; unbedingtes Collatz benötigt Strip-Brücke [C].
		\item \textbf{Syracuse Entropy Compression:} Entropy-Good $\implies \text{thr} < 1$ [A]; keine vollständige Partition.
		\item \textbf{CylinderLift31/447:} Zellenkontraktion + Zylinder-Stabilität [A]; 447 auf PR \#118 nur als leerer Scaffold integriert.
		\item \textbf{PR \#118 Draft:} CI-fähiger Kern, \textit{packaged 8}, Build Green, strikte Claim-Wall.
		\item \textbf{Pre-\#119 Offline Phase-0/1:} Core81 ($\approx 50\%$ für $\equiv 31$); 447-Compressor / Hard-17 / steps150; Lean-Emits lokal grün.
		\item \textbf{Master-Evaluator Gap-Matrix:} Aufschlüsselung in Covered / TooLong / Unassigned unter $\Mref$ [B].
		\item \textbf{Prefix \texttt{[1,1,1,1,2,2]}:} $100\%$ Invariante im $\equiv 31$-Katalog [B]; strukturelle Prefix-Hypothese [C].
		\item \textbf{ContinuationPartition31:} Scaffold zum HardAncestor-Cover; verbleibender \textbf{Hauptblocker} [C].
	\end{enumerate}
	
	\section{Würdigung}
	
	\begin{itemize}
		\item \textbf{Beiträge:} Formale Kontraktions- und Glue-Schicht; reproduzierbare Offline-Pipelines; Lean-Drafts ohne Overclaiming.
		\item \textbf{Disziplin:} Strikte Claim-Governance; Freeze bei Billing-CI; $100\%$ Sample-Abdeckung explizit als [B] $\neq$ unendliche Partition deklariert.
		\item \textbf{Tooling / Offline-Prep:} Kritischer Pfad entkoppelt -- Vorbereitung für PR \#119 während PR \#118 an der Haltelinie wartet.
	\end{itemize}
