## Dynamics

\[
U(n)=\frac{3n+1}{2^{\nu_2(3n+1)}}.
\]

For a block

\[
n_0\to n_1\to\cdots\to n_r
\]

\[
A_r=\sum_{j=0}^{r-1}\nu_2(3n_j+1)

\[
E_r=A_r-r\log_2 3.
\]

Because of the affine \(+1\) terms, \(E_r>0\) is not by itself
declared to be a formal proof that \(n_r<n_0\).
